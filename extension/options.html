Gallery

Windows 图片归档与标签图库

常规

命中接收网站的图片，下载完成后交给桌面端自动归档；归档不了的会在桌面端浮层提醒你处理。下载位置用浏览器原生的「另存为」对话框自己选。

开启后不受网站规则限制。仍由浏览器选择保存位置，下载完成后加入 Gallery 待归档；没有来源标签或分级时留空。不扫描网页中未下载的图片。

在网页图片上按住拖动，右侧会浮出黑洞，丢进去就下载并进入待归档。只能写在浏览器默认下载目录下的子目录里（扩展写不到其他盘符）。

接收网站

Danbooru 支持帖子原图链接和下载按钮；Pixiv 与 Pinterest 会自动记录画师、来源，Pixiv 的标签只保留你库里已有的作品与角色。其他网站下载可以接收，标签需要在桌面端确认。

桌面连接

从 Gallery 桌面端「设置 → 浏览器连接」复制配对码。

高级连接设置

桌面离线时不会丢弃队列。取消或失败的下载不会归档。
