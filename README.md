# Gallery

Windows 桌面图库。把电脑里的图片和视频集中起来看，按日期浏览、打标签、整理归档；也能接住浏览器下载的图片，先审一遍再入库。

适用于 Windows 11 x64。

## 第一次使用

1. 用安装包安装，或解压免安装 ZIP 后运行 `Gallery.exe`。
2. 启动后图库是空的。点左侧「图库」一行右端的加号按钮（或右键「图库」选「添加文件夹」），选择你放图片的目录。
3. 只有添加过的目录才会显示。原图不会被移动或删除，Gallery 只建索引。

安装包已自带 .NET 和 Windows App SDK，不需要另外安装。程序里的图片编辑和审阅窗口用到 WebView2，系统中需要有 Edge 或 WebView2 Runtime。

## 各模块做什么

| 模块 | 能做什么 |
| --- | --- |
| **图库** | 按日期分组浏览图片和视频，支持方格与河流两种排版；可搜索、筛选、排序、多选。右侧时间线可快速跳到某个月。 |
| **看图** | 点图片打开大图，支持缩放、拖动和键盘翻页；底部胶片条列出同一文件夹的其他图片。可设为桌面背景或锁屏。多张图可拼成长图。MP4 直接播放。 |
| **待审核** | 浏览器推来的图片先进这里，不直接进图库。单张逐张确认，或用批量工作台一次处理很多张；标签可用「喷涂」方式快速贴到图上。确认后才归档。 |
| **导入与归档** | 从资源管理器右键把图片交给 Gallery 导入；归档时可选择复制或移动文件，并按标签自动分到不同目录。 |
| **资料库** | 导入别人做好的角色／作品标签包，让标签匹配更准；也能把自己整理好的资料导出成包分享。没有资料包也能正常看图。 |
| **智能识别** | 可选功能。装一个识别模型后，自动给图片打上角色、作品、类型等标签。模型按需加载，不用不占资源。 |
| **浏览器插件** | Chrome / Edge 扩展。在支持的网站上下载图片时，自动把来源、标签等信息推给 Gallery 进待审核。需要先在设置里配对。 |
| **存储与诊断** | 查看缓存占用、清理缩略图、导出个人规则备份、查看错误记录。 |
| **关于** | 查看当前版本、检查更新。默认启动时检查一次，也可手动检查；发现新版后由你决定是否下载安装。 |
| **设置其他项** | 开机自启、主题、目录规则、搜索历史、新图片提醒等。 |

## 从资源管理器直接打开

在文件的「打开方式」里选 Gallery，就能直接看图或播放视频，不会自动加入图库。重复打开同一文件会切到已有窗口，底部胶片条列出同目录内容。

图片右键选「导入归档」才会真正入库。默认复制文件、保留原图；选移动时原文件会被搬走。

## 你的数据在哪

Gallery 不把图片本身存进程序目录，你的东西都在这两个位置：

- `%APPDATA%\Gallery`：设置、个人规则、目录配置。
- `%LOCALAPPDATA%\Gallery`：图库索引、缩略图缓存、资料包和模型。

卸载或更新程序不会删这些数据。移除图库目录也不会删磁盘上的原图。

## 更新与卸载

- 程序默认启动时检查一次更新，也可在「设置 → 关于」里手动检查。发现新版后由你决定是否下载；下载完成后点「安装并重启」，程序会先保存当前工作，再替换文件并重新打开。旧设置和图库数据会保留。
- 安装版用系统「应用和功能」卸载；免安装版直接删掉解压目录即可。
- 关窗默认缩到托盘，完全退出请用托盘菜单里的「退出」。
