# Gallery

更新时间：2026-10-26 11:42（Asia/Tokyo）；本次文档整理时间，不代表重新运行或验收。

## 构建与运行

Windows 11；.NET 9、WinUI 3 / Windows App SDK 2.5.1；ONNX 使用 `Microsoft.ML.OnnxRuntime.DirectML 1.20.1`。依赖版本以 `Gallery.csproj` 为准。

构建命令、唯一输出路径、进程关闭及后台沙箱验证规则统一见 [AGENTS](AGENTS.md#一构建验证与改动边界)。用户从约定目录启动 `Gallery.exe`；`RestartAgent.exe` 等 SDK 文件是运行依赖。

## 当前能力与状态

- 图库使用稳定 ID、虚拟化方格／河流布局；日期排序配时间线，其他排序使用连续条。操作速查见 [UI](UI_CONVENTIONS.md#常用操作速查)。
- 图库内查看器为主窗口覆盖层；外部文件可用轻量独立窗口打开，行为见 [外部文件查看](FILE_VIEWER.md)。图片支持飞入／飞回、指针锚定缩放；mp4 使用独立播放表面。[视频文档](VIDEO_SUPPORT.md#三状态) 保留计划与实现差异。
- 设置为首页＋六个二级页：导入与归档、资料库、智能识别、浏览器插件、存储与诊断、关于；页面常驻。
- 资料库可增量导入多个包，也可一键打包导出（全部源包 + 合并后的实体关系）供他人导入；识别仅保留单个 PixAI 模型；个人规则与公共包分开，详情见 [资料包与个人规则](PACKS_AND_RULES.md)。
- 待审核支持单图圆环和批量标签工作台；数据当前为 schema v7，身份与角色皮肤独立保存，见 [归档文档](ARCHIVE_REVIEW.md)。
- 关于页提供版本、检查更新和启动检查开关；更新合同、分发内容及故障日志边界见 [分发说明](DISTRIBUTION.md)。

状态按专题维护：实现差异与未验证项留在所属章节，不从旧构建或旧交接恢复为“已验收”。标签候选接线见 [身份边界](ARCHIVE_REVIEW.md#候选选择与实现边界)，播放与维护差异见 [视频状态](VIDEO_SUPPORT.md#三状态)，其余验证限制见各专题文末。后续工作范围由用户当前授权确定。

## 文件地图

| 位置 | 职责 |
| --- | --- |
| `MainWindow.xaml(.cs)` | 窗口、导航、标题栏、全屏及退出协调 |

| `assets/` | 示例、图标、词库及模型相关配置资源 |
