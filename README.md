# Gallery

Windows 桌面图库，C# / WinUI 3。支持真实目录扫描、虚拟化方格／河流布局、图片与 mp4 预览、标签与身份资料、浏览器下载接收、待审核及归档。

## 构建与运行

Windows 11；.NET 9、WinUI 3 / Windows App SDK 2.5.1，自带 Windows App SDK 运行依赖。运行时 ONNX 包为 `Microsoft.ML.OnnxRuntime.DirectML 1.20.1`。

构建前关闭正在运行的 Gallery，只使用仓库内既定输出目录：

```powershell
dotnet build Gallery.csproj -c Debug --no-restore -p:CopyRetryCount=0
```

交付要求 0 警告、0 错误。用户启动 `D:\Projects\Other\Gallery\bin\Debug\net9.0-windows10.0.19041.0\win-x64\Gallery.exe`；助手不启动／操作应用做 UI 验收。`RestartAgent.exe` 等 SDK 文件是运行依赖，不是测试副本。

## 当前能力

- 图库按稳定 ID 管理选择、焦点及滚动锚点；`ItemsRepeater`／`VirtualizingLayout` 只实现附近瓦片，日期排序配时间线，其他排序用连续条。
- 文件操作实际执行：删除进回收站，复制／移动／重命名走现有确认与生命周期。F5 后台重扫当前根目录，停在“全部”时扫全部启用根。
- 查看器是主窗口覆盖层；图片飞入／飞回、滚轮指针锚定缩放；全屏退出到最大化时阻止临时普通窗口尺寸落地，用户已反馈该复现场景修复有效。实现与废弃路径只维护在 UI 规范。
- 设置为首页＋导入与归档、智能识别、浏览器插件、存储与诊断四个二级页；页面常驻，切页不重建识别任务。
- 单模型 PixAI v1.0；自动／CPU／GPU 三档，GPU 保留 CPU 执行器，回退原因写结果尾注。阈值、写入范围与设备边界见加载及归档文档。
- 待审核默认左右 70:30；单图圆环与批量虚拟化网格，右侧独立标签工作台，标签搜索／喷涂／撤销／回收规则见归档文档。
- 当前数据库为 schema v7；标签稳定键及身份与词库分离，角色与皮肤分表保存，皮肤缺中文显示原名＋“待译”，不得猜译。
- mp4 仅由图库根目录扫描接入，自动播放带声音；不进入待审核，不参与图片解码、自动分级／模糊、整理或去重。
- 未处理异常写数据目录 `crash.log`；后台诊断写 `%TEMP%\ptv\gallery-log.txt`，不靠全局吞异常维持运行。

## 常用操作

| 操作 | 行为 |
|---|---|
| 单击缩略图 | 普通模式打开预览；选择模式切换该图勾选 |
| Ctrl + 单击 | 进入选择模式，独立切换该图，保留其他选中项 |
| Shift + 单击 | 按当前排序/筛选后的完整列表，从最近一次单图选择的锚点选到点击项；无锚点时仅选当前项 |
| Ctrl + Shift + 单击 | 保留已有选区，追加上述范围 |
| Ctrl+A | 进入选择模式，全选当前排序/筛选后的完整列表，包含屏幕外图片 |
| 方向键 / Shift+方向键 / Ctrl+Shift+方向键 | 左右按列表顺序跨排衔接，上下按相邻行画面位置移动，列表首尾不循环且保留选区 / 从固定锚点范围选择 / 追加范围；首次无焦点时只建立焦点 |
| Space | 切换焦点图勾选，更新选择锚点 |
| Enter / F2 / F3 | 打开焦点图 / 重命名焦点图 / 在资源管理器定位焦点图 |
| Delete | 选区优先，无选区时取焦点图；一次确认弹窗、默认取消，确认后移入回收站 |
| Ctrl+C / Ctrl+Shift+C | 选区优先、焦点兜底，复制文件列表 / 文件路径；单图像素复制通过右键“复制图片内容” |
| F5 | 重扫当前所在目录并刷新网格；停在「图库/全部」时重扫全部已添加目录。后台进行，不打断浏览，结束后用通知条报告新增/更新/移出数量 |
| 拖动缩略图 | 拖动时只跟随 96px 小缩略图；从已选图片起拖时以复制语义拖出整个选区（拖到资源管理器为复制），拖到侧栏目录则二次确认后批量移动；多选时从未选图片起拖，改为只选中并拖出该图；缺失文件或模糊保护命中时取消整次拖出 |
| 点击窗口 XAML 内非交互空白 / Esc | 清空选区并退出选择模式；卡片、按钮、输入框、滚动条等交互区域不触发空白退出；查看器打开时 Esc 优先处理查看器 |
| 预览中 `Esc` / `←` / `→` | 全屏时先退出全屏，再关闭 / 上一张 / 下一张；视频内容区 `Space` 播放或暂停 |
| 右键缩略图 | 图库文件操作菜单；非多选时提供“选择”进入多选；图片（视频除外）提供“设置为桌面背景”，超过 20 MB 只提示、不生效；单图提供“复制图片内容”（视频不提供） |
| 滚动/悬停 | 滚动时右侧时间线淡入，2 秒后淡出 |
| 拖动时间线轨道 | 按位置定位（标记无动画跟随） |
| 汉堡键 | 折叠/展开左侧导航（320 ↔ 48） |
| 导航「图库 / 收藏夹」 | 切换数据源，内容淡出 30ms / 淡入 20ms |
| 搜索框 | 按文件名过滤 |
| 命令栏 | 选择、排序、筛选、库类型与大小、更多（全选/不选） |
| 标题栏齿轮 | 打开设置页（整页替换内容区，标题栏与导航保留） |
| 设置 · 应用主题 | 浅色 / 深色 / Windows 默认，切换即时生效 |

无输入框、菜单、模态占用时才分发图库快捷键；完整焦点、候选 Tab、控件自身键位和鼠标规则见 UI 规范。幻灯片按钮按约定不提供。
