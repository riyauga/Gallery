# Gallery

Windows 11 x64 桌面图库：按日期浏览图片和视频、打标签、整理归档，也能接收浏览器下载的图片先审再入库。

## 配置流程

### 1. 下载

- 程序本体（必选）：[GitHub 发布页](https://github.com/riyauga/Gallery/releases) 下载安装包或免安装 ZIP。
- [资料库（可选）](https://github.com/riyauga/Gallery/releases/download/v1.5.1/Gallery-1.5.1-catalog.zip)：作品、角色、别名和登场关系。
- [识别模型（可选）](https://github.com/riyauga/Gallery/releases/download/v1.4.1/Gallery-1.4.1-pixai-tagger-v1.0.zip)：约 900 MB，自动打角色／作品／类型标签。模型来自 PixAI，请遵守其授权条款。

### 2. 安装与浏览器插件

- 双击安装包，或解压 ZIP 运行 `Gallery.exe`。已自带 .NET 和 Windows App SDK；编辑和审阅窗口需要系统有 Edge 或 WebView2 Runtime。
- 启动后点左侧「图库」的加号添加图片目录。
- 浏览器插件（可选）：支持 **Chrome / Edge 130+**，目录为分发包里的 `extension/`。
  1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），开启「开发者模式」。
  2. 点「加载已解压的扩展程序」，选中 `extension/` 目录。
  3. 在 Gallery「设置 → 浏览器插件」开启桥接，点「复制连接配置」。
  4. 在插件「设置 → 桌面连接」粘贴保存，点「测试连接」。升级后需重新加载插件。

### 3. 导入可选项

- 资料库 ZIP 拖进「设置 → 资料库」；重复内容按提示选择合并方式。
- 模型 ZIP 拖进「设置 → 智能识别」，或解压后导入 `pixai-tagger-v1.0` 文件夹；导入新模型前先移除旧模型。

### 4. 归档目录

- 「设置 → 导入与归档 → 归档根目录」选根目录（限已登记图库），再在「自动归档路径 → 默认路径」点「添加一级」配置子目录，最多 8 级：
  - **自定义名称**：直接填写目录名称。
  - **按标签**：选作品／角色／作者／类型／分级／自定义；勾「以标签名作为目录名」则用该图的标签值，不勾则填固定名；另填无数据时的兜底名。
  - **按来源站点**：从来源网址识别 x、danbooru、pixiv、pinterest，识别不出用域名。
  - **按导入时间**：精确到年／月／日。
- 每一级选择「按标签」时，可通过「标签选取方式」独立选择填写顺序（默认）或文字顺序。列表按顺序显示一级目录、二级目录等，上下交换后同步更新。未配置默认路径且未命中条件时直接进根目录；审核页手工指定目录优先。
- 「条件覆盖 → 添加条件」选择标签和作用位置：含任意一个所选标签即可命中。可只改当前目录名、沿用默认下级，也可自定义整段下级路径；同一位置命中多条时使用列表中的第一条，可上下调整优先级。

标签文字及文本输入支持双击选片段（以下划线等分隔）、三击选整行，可选中后复制。

图库中右键图片选择“编辑标签”，可在弹窗右上角使用“AI分析”。角色、作品、分级有结果时替换，类型去重追加，作者与自定义保留；保存后写入，取消丢弃。多选时各图保留自己的标签和分析结果。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| **图库** | 按日期分组浏览图片和视频，方格／河流排版，搜索、筛选、排序、多选，右侧时间线快速跳转。 |
| **看图** | 大图缩放拖动、键盘翻页、底部胶片条；可设桌面背景或锁屏，多图拼长图，MP4 直接播放。 |
| **待审核** | 浏览器推来的图片先审后入库，支持单张和批量工作台、标签喷涂。 |
| **导入与归档** | 从资源管理器右键导入；归档可复制或移动文件，并按逐级目录配置分流。 |
| **资料库** | 查看编辑作品、角色与登场关系，设置背景图，导出／导入资料库 ZIP 和个人规则备份。 |
| **智能识别** | 装模型后自动打角色、作品、类型标签，按需加载。 |
| **浏览器插件** | Chrome / Edge 扩展，在支持的网站下载图片时推送到待审核。站点与配对细节见 [插件说明](extension/README.md)。 |
| **存储与诊断** | 查看缓存、清理缩略图、导出个人规则、查看错误记录。 |
| **关于** | 查看版本、检查更新。 |

## 其他

- 图片右键「打开方式」选 Gallery 可直接看图，不加入图库；右键「导入归档」才入库。默认复制保留原图，选移动则搬走文件。
- 数据位置：`%APPDATA%\Gallery` 存设置与个人规则；`%LOCALAPPDATA%\Gallery` 存索引、缩略图、资料包和模型。更新和卸载不会删这些数据。
- 程序默认启动时检查更新，也可在「设置 → 关于」手动检查。发现未跳过的新版本后，「关于」入口会保留提示点，直到更新完成或明确跳过该版本。更新保留旧设置和数据；安装版用系统「应用和功能」卸载，免安装版直接删目录。
- 关窗默认缩到托盘，完全退出用托盘菜单「退出」。
